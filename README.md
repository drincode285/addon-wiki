# Teru's Addon Wiki

Mobile-first, player-friendly Minecraft: Bedrock Edition add-on wiki by **terutherabbit**, ready for Vercel.

## Deploy to Vercel
1. Upload this folder to GitHub or import it in Vercel (Framework Preset: `Other`, empty Build Command).
2. Deploy to get clean URLs like `/` and `/addons/dungeons-of-relic`.

## Update CurseForge Links & Add Future Add-ons
- Edit `data/addons.js` to set your live `curseforgeUrl` or add new add-on cards.
- Copy `addons/_template.html` to `addons/<new-addon>.html` for each new add-on guide.
